What the numbers mean

Decode and prefill are medians of the engine-reported rates. The first completion is a warm-up and is not counted.

Peak model RAM comes from Needle itself when the engine reports a positive value; current WASM builds may return an unavailable sentinel. WASM heap is the reliable cross-model comparison: the worker's allocated linear memory after inference, including the engine, model, caches, and allocator headroom.

Workers run one at a time and are terminated afterward. This avoids counting both models in memory simultaneously.
